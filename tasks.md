# WordPress starter project tasks

This backlog tracks optional improvements to the clean WordPress starter. Keep the installation minimal; take on a task only when the project needs it.

## Foundation

- [ ] Confirm the supported WordPress and PHP versions and document them.
- [ ] Add a project-specific child theme only when a design customization is required.
- [ ] Add a custom plugin only when functionality cannot be provided cleanly by WordPress core.

## Content and presentation

- [ ] Configure the site title, tagline, language, timezone, and permalink structure for the target site.
- [ ] Create only the pages and navigation required by the site owner.
- [ ] Review the active theme's templates and mobile/accessibility behavior before launch.

## Operations and launch

- [ ] Set up a repeatable database and files backup process.
- [ ] Configure a staging environment separate from production.
- [ ] Configure production hosting, HTTPS, domain, and secure database credentials.
- [ ] Confirm search visibility, privacy, user accounts, updates, and plugin requirements before launch.
- [ ] Test forms, media uploads, backups, restore procedures, and essential pages.
- [ ] Check performance and accessibility using the target site's real content.
